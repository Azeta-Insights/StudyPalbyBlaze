# StudyPal by Blaze (Web Application)

An offline-first exam preparation web app for Nigerian secondary school students preparing for **JAMB UTME**, **WAEC WASSCE**, and **NECO SSCE**, featuring friendly AI study companion **Blaze**.

## Key Features

- **Blaze Mascot Companion**: Animated vector mascot with stateful moods (`HAPPY`, `CELEBRATING`, `THINKING`, `EMPATHETIC`, `SALUTING`) and grounded dynamic dialogue responding to student milestones.
- **1,049 Authentic Past Questions**: Fully loaded offline database spanning Mathematics, English Language, Biology, Government, Physics, and Commerce with mathematical notation, comprehension reading passages, and diagram zoom.
- **SuperMemo SM-2 Spaced Repetition**: Memory reinforcement engine that calculates dynamic intervals, repetitions, and easiness factors for long-term retention.
- **Daily Streak System & 7-Day Trial Reward**: Streak tracking that unlocks 7 days of free Blaze Premium upon completing a 7-day study streak.
- **CBT Timed Mock Simulation**: Real Computer-Based Test experience with live countdown timer, interactive Question Palette grid, bookmarking/flagging, and question-by-question review.
- **Frosted Glass UI**: Modern glassmorphic theme with Blaze orange accents, dark navy surfaces, and responsive mobile-first layouts.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Frosted Glass design system
- **Build**: Vite
- **Icons & Visuals**: Lucide React + Canvas Confetti
- **Storage**: Offline-first client persistence
